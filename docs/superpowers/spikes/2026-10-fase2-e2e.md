## Bug encontrado y arreglado

`createReturnPicking` escribía `picking_type_id` en la devolución recién creada:
Odoo responde **"Cambiar el tipo de operación de este registro está prohibido en
este momento."** La devolución quedaba creada sin `origin` (LL/RET/02574,
cancelada a mano). Arreglo (Reportes `aedc9a4`): solo se escribe `origin`; el
tipo lo pone Odoo (LL: "Devoluciones"); si la escritura falla, el error incluye
el id del remito.
